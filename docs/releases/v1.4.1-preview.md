# CueBell 1.4.1 preview

This Android preview includes the simpler interface already available on the web.

## What changed

- Shorter labels and help text across the interface and translations.
- Alerts show the main result first; **Details** contains source text and supporting information.
- Live captions start collapsed and can be expanded while listening.
- **Home → Stop Listening** pauses capture. **Settings → Clear task** removes the task and history.
- Includes the current microphone-stream recovery fixes from `main`.

## Install and use

Download the ARM64 APK from this release. Version **1.4.1**, Android version code **8**, development-signed preview. It uses https://cuebell.mathewjoseph.xyz.

Follow the [user guide](../../DEMO.md). Noise reduction remains experimental and off by default. This is a supplemental aid, not an official queue display or emergency alarm.

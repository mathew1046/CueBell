# CueBell 1.4.0 preview

Experimental on-device noise reduction is now available for hands-on testing.

## Try it

1. Install the ARM64 APK as an update to the existing CueBell preview.
2. Open **Settings → Listening → Noise reduction** and enable it.
3. Start a spoken request or monitoring session. Stop listening before toggling
   noise reduction for a comparison.

The setting is off by default. The published APK uses the tested FFT runtime and
GTCRN model, with bounded fallback and a 16 ms causal alignment delay.

## Observations

Five genuine railway-station recordings processed fully on the phone. Estimated
noise quality improved, but platform/time recognition regressed on one repeated
case. This is an experimental preview for user testing, not an accuracy-qualified
default. The recorded observations and source attribution remain available:

https://github.com/mathew1046/CueBell/blob/main/docs/STATION_PA_DENOISING_2026-11-14.md

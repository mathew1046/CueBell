The original 6 November research plan described a queue-only, foreground-web MVP. It is retained in [Git history](https://github.com/mathew1046/CueBell/blob/12573af/implementation.md), not as current setup instructions. Later implementation added general listening tasks, native Android capture, automatic task activation, an explicit OpenAI text fallback and optional local GTCRN.
